2. Qué datos tratamos y para qué

Si nos escribes un correo

  • Para qué: para responderte.

Al visitar la web

No tenemos registro de usuarios, formularios ni comentarios, y no usamos herramientas de analítica. Aun así, al visitar cualquier web tu navegador envía algunos datos técnicos (como la dirección IP) a los servicios que la hacen funcionar:

  • GitHub Pages (GitHub, Inc.), donde está alojada la web. Puede registrar la dirección IP de los visitantes por motivos de seguridad.
  • Google Fonts (Google), que sirve los tipos de letra de la web. Tu navegador se conecta a sus servidores para descargarlos.
  • Google AdSense (Google), que muestra la publicidad de la web. Ver el apartado Cookies y publicidad.

Estos proveedores pueden estar fuera del Espacio Económico Europeo; tratan los datos según sus propias políticas de privacidad y las garantías que prevé el RGPD para estas transferencias.

3. Con quién compartimos tus datos
